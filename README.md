* 🛠️ **Current Focus:** Java/Spring Boot, Laravel, React, Vue 3, TypeScript, SQL and API integrations.
* 🔄 **Systems Delivery:** Workflow design, process optimisation, synchronisation, reconciliation and production support.
* 🔒 **Security & DevOps:** Multi-tenant data isolation, authentication, CI/CD, Docker, Kubernetes and GitOps.

### 🚀 Flagship Solo Product: TechMart Africa

A production-grade, multi-tenant SaaS POS and e-commerce platform, self-hosted on Hetzner through Easypanel and Docker.

The platform includes offline-first POS workflows, inventory reconciliation, split payments, KRA eTIMS/DigiTax integration, payroll functionality, real-time updates and automated security regression testing for tenant data isolation.

* 🌐 **Storefront:** [techmartafrica.org](https://techmartafrica.org)
* 🏪 **POS System:** [pos.techmartafrica.org](https://pos.techmartafrica.org)
